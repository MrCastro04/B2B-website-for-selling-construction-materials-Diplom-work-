# 🏗️ Магазин будівельних матеріалів — Backend API

## ⚡ Запуск (копіюй і вставляй в термінал)

**Перший раз (встановлення залежностей):**
```bash
cd backend
npm install
npm run dev
```

**Наступні рази:**
```bash
cd backend
npm run dev
```

> ✅ Після запуску відкрити у браузері: **http://localhost:5000**

---

Дипломний проект. REST API для інтернет-магазину будівельних матеріалів з авторизацією, каталогом товарів та системою замовлень.

---

## Технології

| Шар         | Технологія                           |
|-------------|--------------------------------------|
| Backend     | Node.js + Express.js                 |
| База даних  | MySQL 8.0                            |
| Авторизація | bcryptjs (хешування паролів)         |

## 🚀 Як запустити сайт

### Крок 1 — Встановити програми

Якщо ще не встановлено:

- **Node.js** → завантажити з [nodejs.org](https://nodejs.org/) (кнопка LTS) → встановити
- **MySQL 8.0** → завантажити з [dev.mysql.com](https://dev.mysql.com/downloads/mysql/) → встановити

Перевірка після встановлення (у терміналі):
```bash
node --version
npm --version
```

---

### Крок 2 — Скопіювати проект

```bash
git clone https://github.com/MrCastro04/Diplom_Site.git
cd Diplom_Site
```

---

### Крок 3 — Налаштувати базу даних

1. Відкрити **MySQL Workbench**
2. Підключитись до локального сервера
3. Виконати файл `add_products.sql` — він створить таблиці та заповнить тестовими даними:
   - File → Open SQL Script → вибрати `add_products.sql` → натиснути ⚡ (Execute)

---

### Крок 4 — Створити файл `.env`

У папці `backend/` створити файл `.env` з таким вмістом:

```env
PORT=5000
DB_HOST=localhost
DB_PORT=3306
DB_USER=root
DB_PASSWORD=твій_пароль_від_MySQL
DB_NAME=construction_shop
```

> ⚠️ Замінити `твій_пароль_від_MySQL` на реальний пароль, який вводився при встановленні MySQL.

---

### Крок 5 — Встановити залежності

```bash
cd backend
npm install
```

---

### Крок 6 — Запустити сервер

```bash
cd "Root Diploma/Diploma/Diplom_Site/backend"
npm run dev
```

У терміналі повинно з'явитись:
```
🚀 Сервер запущено на http://localhost:5000
✅ Підключення до MySQL успішне!
```

---

### Крок 7 — Відкрити у браузері

```
http://localhost:5000
```

---

### ❗ Часті проблеми

| Проблема | Рішення |
|----------|---------|
| `❌ Помилка підключення до MySQL` | Перевір пароль у `.env` або чи запущений MySQL |
| `Error: Cannot find module` | Виконай `npm install` у папці `backend/` |
| Порт 5000 зайнятий | Зміни `PORT=5001` у `.env` |
| `node: command not found` | Встанови Node.js з nodejs.org |

## API Endpoints

| Метод  | URL                    | Опис                              |
|--------|------------------------|-----------------------------------|
| GET    | `/`                    | Перевірка роботи сервера          |
| GET    | `/api/products`        | Усі товари                        |
| GET    | `/api/categories`      | Усі категорії                     |
| GET    | `/api/products/:id`    | Один товар за ID                  |
| POST   | `/api/register`        | Реєстрація користувача            |
| POST   | `/api/login`           | Вхід користувача                  |
| POST   | `/api/orders`          | Створити замовлення (транзакція)  |
| GET    | `/api/orders/:name`    | Історія замовлень покупця         |
| GET    | `/api/admin/orders`    | Усі замовлення (адмін)            |

## Особливості

- **Транзакції MySQL** — при оформленні замовлення перевіряється наявність товару на складі та автоматично списується кількість
- **Безпечна авторизація** — паролі зберігаються у вигляді bcrypt-хешу
- **Валідація** — email тільки @gmail.com, пароль мінімум 6 символів
