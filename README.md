# 🏗️ Магазин будівельних матеріалів — Backend API

Дипломний проект. REST API для інтернет-магазину будівельних матеріалів з авторизацією, каталогом товарів та системою замовлень.

---

## Технології

| Шар        | Технологія              |
|------------|-------------------------|
| Backend    | Node.js + Express.js    |
| База даних | MySQL 8.0               |
| Авторизація | bcryptjs (хешування паролів) |

---

## Структура проекту

```
Diplom_Site/
├── backend/
│   ├── server.js          # Express-сервер + всі API маршрути
│   ├── package.json
│   └── .env               # Налаштування БД (не у репо)
├── add_products.sql        # SQL для додавання товарів
├── sql_updates.sql         # SQL-оновлення схеми
└── README.md
```

---

## Запуск проекту

### 1. Вимоги

- [Node.js](https://nodejs.org/) LTS
- [MySQL 8.0](https://dev.mysql.com/downloads/)

### 2. Налаштувати `.env`

Створити файл `backend/.env`:

```env
PORT=5000
DB_HOST=localhost
DB_PORT=3306
DB_USER=root
DB_PASSWORD=твій_пароль
DB_NAME=construction_shop
```

### 3. Встановити залежності та запустити

```bash
cd backend
npm install
npm run dev
```

Сервер запуститься на `http://localhost:5000`

## API Endpoints

| Метод  | URL                    | Опис                              |
|--------|------------------------|-----------------------------------|
| GET    | `/`                    | Перевірка роботи сервера          |
| GET    | `/api/products`        | Усі товари                        |
| GET    | `/api/categories`      | Усі категорії                     |
| GET    | `/api/products/:id`    | Один товар за ID                  |
| POST   | `/api/register`        | Реєстрація користувача            |
| POST   | `/api/login`           | Вхід користувача                  |
| POST   | `/api/orders`          | Створити замовлення (транзакція)  |
| GET    | `/api/orders/:name`    | Історія замовлень покупця         |
| GET    | `/api/admin/orders`    | Усі замовлення (адмін)            |

## Особливості

- **Транзакції MySQL** — при оформленні замовлення перевіряється наявність товару на складі та автоматично списується кількість
- **Безпечна авторизація** — паролі зберігаються у вигляді bcrypt-хешу
- **Валідація** — email тільки @gmail.com, пароль мінімум 6 символів
